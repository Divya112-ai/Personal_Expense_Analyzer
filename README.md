# 💰 Personal Expense Analyzer

> Python for Data Science — GTU PBL Micro Project

A beginner-friendly Python data-analysis project that analyzes personal expenses and provides useful insights about spending patterns.

## 🎯 Problem Statement

People often spend money on different categories such as food, transportation, shopping, bills and entertainment but may not clearly understand where most of their money is going.

This project analyzes expense data automatically and provides:

- Total expenditure
- Average daily expenditure
- Category-wise expenditure
- Highest spending category
- Highest spending day
- Top individual expenses
- Spending distribution
- Daily spending trends

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- CSV
